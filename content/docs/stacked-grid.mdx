## Features

- Pure inline SVG — no dependencies, scales crisply
- True 2:1 isometric projection with painter's-algorithm occlusion
- Radial height field produces a stepped-pyramid shape
- Emerald gradient peak at the center

## Props

| Prop        | Type     | Default | Description                        |
| ----------- | -------- | ------- | ---------------------------------- |
| `className` | `string` | -       | Extra classes for the wrapper      |
| `gridSize`  | `number` | `6`     | N×N cube grid dimension            |
| `unit`      | `number` | `24`    | Iso projection unit in SVG pixels  |
