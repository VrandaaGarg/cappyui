## Features

- **Pure inline SVG**: Zero dependencies beyond `clsx`/`tailwind-merge` — scales crisply at any size
- **True 2:1 isometric projection**: `iso(x,y,z,s)` with light from top-left implied
- **Painter's algorithm**: Back-to-front sorted by `x + y + z` for correct occlusion
- **27-cube lattice**: 3×3×3 cluster with top-corner cubes omitted (top layer is cross-shaped)
- **Orange spine**: Brand cubes form a vertical axis — base center, plus-shaped middle layer, cap on top
- **Trail particle dots**: Orange dots flow in from both sides like data being ingested
- **Auto-saved pill**: Dark rounded pill with green status dot and mono label
- **Subtle plate**: 5×5 iso grid plate with 4% white gridlines
- **Memoized derivation**: Cubes and plate lines computed once, never hand-written 27 times
- **Optional dot animation**: CSS-only pulse loop when `animateDots` is true

## Props

| Prop           | Type      | Default         | Description                                                     |
| -------------- | --------- | --------------- | --------------------------------------------------------------- |
| `className`    | `string`  | -               | Extra classes applied to the wrapper                            |
| `showPill`     | `boolean` | `true`          | Render the "auto-saved" status pill                             |
| `pillLabel`    | `string`  | `"auto-saved"`  | Pill text content                                               |
| `animateDots`  | `boolean` | `false`         | Enable a CSS-only pulse animation on the trailing dots          |

## Customization

### Animate the particle trails

```tsx
<IsoIntelligentMemory animateDots />
```

### Change the pill label

```tsx
<IsoIntelligentMemory pillLabel="syncing…" />
```

### Hide the pill

```tsx
<IsoIntelligentMemory showPill={false} />
```
