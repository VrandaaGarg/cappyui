## Features

- Pure inline SVG — zero dependencies, scales crisply
- True 2:1 isometric projection with painter's-algorithm occlusion
- 27-cube cluster with a vertical emerald spine through the middle
- Top-corner cubes omitted so the top reads as a cross shape
